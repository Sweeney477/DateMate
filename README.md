# DateMate Landing Page

DateMate is an AI-powered date planning companion designed to run inside ChatGPT. This repository contains a static marketing site that introduces the product vision while we prepare to build the full conversational app experience.

## 📁 Project structure

```
.
├── index.html   # Landing page markup
├── styles.css   # Visual design and responsive layout
├── script.js    # Lightweight interactions for forms and footer
└── README.md    # Project overview and setup instructions
```

## 🚀 Getting started

Open `index.html` in your browser to explore the landing page locally. No build step or external dependencies are required.

## 🧩 Features

- Hero section showcasing the DateMate itinerary experience.
- Feature highlights, conversation flow overview, and development milestones.
- Waitlist forms with basic validation and confirmation messaging.
- Responsive design that adapts to desktop and mobile layouts.
